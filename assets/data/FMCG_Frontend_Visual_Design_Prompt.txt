FRONTEND DESIGN PROMPT — HOW THE FMCG PORTFOLIO WEBSITE SHOULD LOOK
==================================================================

PROJECT
-------
Smart Supply Chain Intelligence — FMCG Analytics Portfolio

PURPOSE
-------
Design a premium, elegant, smooth, highly usable frontend for a static FMCG analytics portfolio website.

The website should look like a professional consulting case study mixed with a modern data-intelligence product.

It must not look like:

- a basic admin dashboard
- a Power BI copy
- a generic SaaS template
- a college mini-project
- a neon cyberpunk website
- a blue corporate dashboard
- a page full of random cards
- a website using emojis as icons

Use only:

- HTML
- CSS
- Vanilla JavaScript
- SVG icons and illustrations
- Chart.js, ECharts, Plotly.js, or D3.js

Do not use:

- Next.js
- React
- Backend
- Database
- Blue colors
- Cyan colors
- Teal-blue shades
- Excessive glassmorphism
- Excessive gradients

==================================================================
OVERALL VISUAL FEEL
==================================================================

The website should feel:

- premium
- editorial
- elegant
- warm
- confident
- data-rich
- modern
- smooth
- minimal but not empty
- attractive enough for a professional portfolio

The visual direction should combine:

1. Luxury editorial design
2. Premium consulting report
3. Modern analytics product
4. FMCG supply-chain storytelling

The website should use strong typography, clean spacing, premium section transitions, subtle motion, and meaningful charts.

The website should not depend only on dashboard statistics.

It must present:

- project story
- dataset
- methodology
- analysis
- charts
- data tables
- business insights
- recommendations
- PDFs
- author portfolio information

==================================================================

The website should remain smooth.

- lazy-loaded charts

- text is not cramped
- sections have a clear narrative

- business insights are clearly visible
- the website looks publishable in a professional portfolio

FINAL RESULT

Create a website that looks like a premium data-intelligence case study, not a classroom dashboard.

It should be visually attractive, smooth, easy to understand, analytically rich, and ready to publish as a professional portfolio project.
