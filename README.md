# Smart Supply Chain Intelligence — FMCG Analytics Portfolio

A premium, fully static FMCG analytics portfolio website.

**Live:** https://fmcg.shivangidwivedi.in

## What's inside

- `index.html` — the one-page site
- `css/styles.css` — styles
- `js/` — app logic and datasets (`app.js`, `cube-data.js`, `data.js`, `sample-data.js`)
- `assets/data/` — analysis files, prompts and frontend data
- `assets/images/` — site images
- `assets/pdf/` — Stage 5 dashboard report

## Run locally

No build step needed — it's fully static. Just open `index.html` in a browser,
or serve the folder:

```bash
npx serve .
```
